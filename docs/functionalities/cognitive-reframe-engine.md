# Functionality: Cognitive Reframe Engine

## Overview
Powered by Meta Muse Spark and Llama 3.3 reasoning models, this engine processes chaotic emotional or cognitive dumps and deconstructs them using proven cognitive-behavioral reframing principles.

## Key Capabilities
1. **Cognitive Distortion Detection:**
   - Detects negative cognitive bias patterns such as *Catastrophizing*, *All-or-Nothing Thinking*, *Premature Optimization*, *Mind Reading*, or *The Imposter Spiral*.
2. **Antagonist Personification:**
   - Identifies and names the psychological "villain" in the user's mind (e.g., *"The Perfectionism Kraken"*, *"The 100-Tab Demon"*, *"The Sunk Cost Poltergeist"*).
   - Gives the antagonist humorous or quirky visual attributes that can be depicted in comic form.
3. **Cognitive Burden Scoring:**
   - Evaluates the initial mental load score (0–100 scale) based on emotional intensity, ambiguity, and multi-variable panic.
   - Calculates the post-reframe burden score, showing the quantitative "Mental Space Freed".
4. **The Core Truth (Reality Check):**
   - Synthesizes a single, grounding 1-sentence reality check that pierces through the panic and restores perspective.
