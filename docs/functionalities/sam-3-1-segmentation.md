# Functionality: SAM 3.1 (Segment Anything) Inspector

## Overview
Demonstrates Meta's state-of-the-art vision segmentation capability (SAM 3.1) applied directly to generated comic panels. Enables interactive exploration of visual assets, character masks, dialogue layers, and scene props.

## Key Capabilities
1. **Interactive Segmentation Mode:**
   - Users can toggle SAM 3.1 Mode on any comic panel.
   - Hovering over panel regions dynamically highlights segment masks with confidence scores.
2. **Layered Object Classes:**
   - **Characters:** Protagonist, Antagonist creature, Supporting figures.
   - **Dialogue & UI:** Speech bubbles, thought bubbles, narration captions.
   - **Expressions & Props:** Face micro-expressions, laptops, medical tools, clocks.
   - **Background:** Scene environment, ambient lighting, atmospheric particles.
3. **Segmentation Mask Inspection:**
   - Visual bounding boxes, category tags, and confidence percentages.
   - Ability to isolate individual elements or toggle visibility for modular editing.
