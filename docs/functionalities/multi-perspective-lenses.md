# Functionality: Multi-Perspective Lenses

## Overview
Allows the user to re-render or reframe the same dilemma through different cognitive and philosophical vantage points using Meta's model steering capabilities.

## Available Lenses
1. **The Empathetic Sage (Caregiver / Best Friend):**
   - Warm, validating, non-judgmental tone.
   - Ideal for burnout, emotional vulnerability, and caregiver fatigue.
2. **The Stoic Philosopher (Marcus Aurelius):**
   - Focuses strictly on the dichotomy of control: what is within your power vs. what must be accepted.
   - Clears away emotional static with ancient pragmatic wisdom.
3. **The Satirical Standup Comic:**
   - Highlights the absurdities of human overthinking.
   - Uses laughter as a therapeutic tool to break amygdala-driven freeze states.
4. **The Pragmatic 10x Engineer:**
   - Cuts through emotional noise; formulates binary tradeoffs, minimum viable fixes, and pragmatic rollouts.
5. **The Candid Realist:**
   - Blunt, gentle honesty with zero corporate fluff or toxic positivity.
