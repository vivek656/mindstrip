# Agent Instructions for MindStrip

Please review the primary guidelines located in the root [`../AGENTS.md`](../AGENTS.md).

### Core Golden Rules:
1. **Maintain Working Memory:** Write useful updates to [`../memory.md`](../memory.md) that will assist future agents and human developers.
2. **Zero Secrets in Git:** Under no circumstances should any API keys, tokens, or credentials be written into any file that can be committed or pushed to Git.
3. **Follow the Functional Specs:** Build in accordance with [`idea.md`](idea.md) and the individual functionality documents in [`functionalities/`](functionalities/).
